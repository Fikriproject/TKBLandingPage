# 🍡 Tape Ketan Bakung Cirebon — Landing Page

Landing page resmi untuk produk **Tape Ketan Bakung**, kuliner fermentasi tradisional khas Cirebon yang terbuat dari beras ketan dan daun katuk.

## 🌐 Live Demo
[[https://tkblandingpage.netlify.app](https://tapeketanbakungcirebon.netlify.app/)](https://tkblandingpage.netlify.app) *(update link setelah deploy)*

---

## 📋 Fitur Halaman

| Section | Keterangan |
|---|---|
| **Hero** | Penjelasan umum produk Tape Ketan Bakung |
| **Manfaat Gizi** | 4 kartu informasi kandungan gizi (Probiotik, Energi, Vitamin B1, Mineral) |
| **Legalitas** | Sertifikasi resmi: P-IRT, NIB, Halal, CHSE, Quality Food |
| **Menu** | 6 produk dengan harga & tombol Order Now ke WhatsApp |
| **Edu Wisata Kuliner** | Paket wisata edukasi pembuatan Tape Ketan Bakung |
| **Kirim Pesan** | Form kontak langsung ke email tapeketanbakungcirebon@gmail.com |
| **Footer** | Informasi kontak, sosial media, dan alamat |

## 🚀 Teknologi

- **HTML5** — Struktur halaman
- **SCSS / CSS3** — Styling dengan variabel dan animasi
- **Vanilla JavaScript** — Lightbox gambar, form mailto, smooth scroll

## 📦 Cara Menjalankan Lokal

Cukup buka `index.html` di browser. Tidak perlu server atau instalasi apapun.

Jika ingin mengedit SCSS dan compile ulang:
```bash
npm install
npx sass styles/styles.scss styles/styles.css --source-map
```
